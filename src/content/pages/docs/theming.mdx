Fulldev UI follows the same CSS variable and semantic token model as shadcn/ui.
Keep component styling on tokens such as `background`, `foreground`, `primary`,
`muted`, `border`, and `ring` instead of hard-coded colors.

## Where to make changes

Start from the copied `src/styles/global.css` baseline. Update values in
`:root` and `.dark`, and keep the `@theme inline` mappings in place so Tailwind
utilities like `bg-background`, `text-foreground`, and `border-border` keep
working across all installed components.

## Styles

Fulldev UI supports the shadcn/ui styles: Vega, Nova, Maia, Lyra, Mira, Luma,
Sera, and Rhea. A style changes the shape of components, such as radius,
density, and type, while your theme tokens keep the colors. Use the style menu
next to any preview to compare them.

With the `@fulldev` registry on `https://ui.full.dev/r/styles/{style}/{name}.json`,
components install in the style from your `components.json`. To switch styles,
apply a shadcn/ui preset and then reinstall your Fulldev UI components:

```bash
npx shadcn@latest apply <preset>
npx shadcn@latest add @fulldev/button @fulldev/card --overwrite
```

`apply` updates `components.json`, fonts, and CSS variables, but only
reinstalls components from the shadcn/ui registry, so the second command is
needed for Fulldev UI components. Use `--only theme,font` to keep your current
style and change only the theme and fonts.

## Tokens to keep in sync

Most projects only need to tune the core surface and action tokens, the sidebar
tokens, and `--radius`. Changing those values is usually enough to make buttons,
cards, inputs, overlays, and navigation feel cohesive without rewriting
component classes.

## Dark mode

If you use the included `ThemeToggle`, render `ThemeProvider` in your
document `<head>` so the saved theme or system preference is applied before the
page paints.

For deeper token guidance, use the official [shadcn/ui theming
docs](https://ui.shadcn.com/docs/theming) and [dark mode
docs](https://ui.shadcn.com/docs/dark-mode) as the reference.
