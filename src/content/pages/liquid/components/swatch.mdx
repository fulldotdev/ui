## Installation

```bash
npx shadcn@latest add https://ui.full.dev/r/liquid/swatch.json https://ui.full.dev/r/liquid/toggle.json https://ui.full.dev/r/liquid/field.json
```

Follow the [one-time layout setup](/liquid/docs/installation/). A full `components` install already includes this item.

## Usage

After this install, render these once in the layout head before theme overrides and other modules. The full `ui` hook already includes them. The command also installs the parts used in this example.

```liquid
{% render 'ui-init' %}
{% render 'ui-swatch' %}
{% render 'ui-triggers' %}
{% render 'ui-runtime' %}
{% render 'ui-toggle' %}
{% render 'ui-input' %}
{% render 'ui-field' %}
```

The preview and its Usage tab render the same native Liquid source. Use `data-slot` for parts, `data-variant` for variants and `data-size` for sizes. Keep your store's labels, translations and Shopify data in your theme.

A swatch shows a color or pattern beside an option or filter value. Set its background from Shopify's swatch, such as `background-color: {{ value.swatch.color }}` or `background-image: url({{ value.swatch.image | image_url: width: 48 }})`. It is decorative, so keep the value's name in text or in the label of its toggle. Option values as links with `aria-current` or as labels around a radio input take the toggle look; see [Toggle](/liquid/components/toggle/).
