## Installation

```bash
npx shadcn@latest add @fulldev/skeleton
```

## Usage

```ts
import { Skeleton } from "@/components/ui/skeleton"
```

```astro
<Skeleton class="h-[20px] w-[100px] rounded-full" />
```

Match the approximate size of the final content to reduce layout shift. Use
`Skeleton` for loading states, not empty states. For no-data UI, use
[Empty](/astro/components/empty/).

`Skeleton` renders a `div` with `data-slot="skeleton"` and passes all other
attributes through.
