## Installation

```bash
npx shadcn@latest add @fulldev/switch
```

## Usage

```ts
import { Switch } from "@/components/ui/switch"
```

```astro
<Switch id="notifications" name="notifications" />
```

`Switch` renders a `span` with `role="switch"` and injects a visually hidden
checkbox for form submission. Label it with a `Label` whose `for` matches the
switch `id`, or wrap it in a `label`.

## API Reference

Source: [`src/components/ui/switch`](https://github.com/fulldotdev/ui/tree/main/src/components/ui/switch)

| Prop             | Type                | Default     |
| ---------------- | ------------------- | ----------- |
| `defaultChecked` | `boolean`           | `false`     |
| `disabled`       | `boolean`           | `false`     |
| `readOnly`       | `boolean`           | `false`     |
| `required`       | `boolean`           | `false`     |
| `name`           | `string`            |             |
| `value`          | `string`            | `"on"`      |
| `uncheckedValue` | `string`            |             |
| `size`           | `"default" \| "sm"` | `"default"` |

See the [data-slot docs](https://github.com/bejamas/data-slot/blob/main/packages/switch/README.md) for events such as `switch:change`.
