## Installation

```bash
npx shadcn@latest add @fulldev/toggle
```

## Usage

```ts
import { Toggle } from "@/components/ui/toggle"
```

```astro
<Toggle>Toggle</Toggle>
```

`Toggle` renders a `button` with `aria-pressed`. Use `defaultPressed` for the
initial state. Style the pressed state with `aria-pressed:` or, on children,
`group-aria-pressed/toggle:`.

## API Reference

Source: [`src/components/ui/toggle`](https://github.com/fulldotdev/ui/tree/main/src/components/ui/toggle)

| Prop             | Type                        | Default     |
| ---------------- | --------------------------- | ----------- |
| `variant`        | `"default" \| "outline"`    | `"default"` |
| `size`           | `"default" \| "sm" \| "lg"` | `"default"` |
| `defaultPressed` | `boolean`                   | `false`     |
| `disabled`       | `boolean`                   | `false`     |

`toggleVariants` gives the same classes to a custom element. See the
[data-slot docs](https://github.com/bejamas/data-slot/blob/main/packages/toggle/README.md)
for events such as `toggle:change`.
