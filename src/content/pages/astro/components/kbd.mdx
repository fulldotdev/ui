## Installation

```bash
npx shadcn@latest add @fulldev/kbd
```

## Usage

```ts
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```astro
<Kbd>Ctrl</Kbd>
```

## Composition

```text

KbdGroup
├── Kbd
└── Kbd
```

## API Reference

Source: [`src/components/ui/kbd`](https://github.com/fulldotdev/ui/tree/main/src/components/ui/kbd)

| Component  | Element | Data Slot   |
| ---------- | ------- | ----------- |
| `Kbd`      | `kbd`   | `kbd`       |
| `KbdGroup` | `div`   | `kbd-group` |

Both take `class` and pass all other attributes through. `KbdGroup` renders a
`div`, so do not nest it in a `p`.
