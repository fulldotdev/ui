## Installation

```bash
npx shadcn@latest add @fulldev/accordion
```

## Usage

```ts
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion"
```

```astro
<Accordion defaultValue={["item-1"]}>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Composition

```text
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
└── AccordionItem
    ├── AccordionTrigger
    └── AccordionContent
```

## API Reference

Source: [`src/components/ui/accordion`](https://github.com/fulldotdev/ui/tree/main/src/components/ui/accordion)

Interactivity comes from [`@data-slot/accordion`](https://github.com/bejamas/data-slot/blob/main/packages/accordion/README.md).

### Accordion

| Prop               | Type                         | Default      |
| ------------------ | ---------------------------- | ------------ |
| `defaultValue`     | `string \| string[]`         |              |
| `multiple`         | `boolean`                    | `false`      |
| `collapsible`      | `boolean`                    |              |
| `disabled`         | `boolean`                    | `false`      |
| `orientation`      | `"vertical" \| "horizontal"` | `"vertical"` |
| `loopFocus`        | `boolean`                    |              |
| `hiddenUntilFound` | `boolean`                    |              |

### AccordionItem

| Prop       | Type      | Default  |
| ---------- | --------- | -------- |
| `value`    | `string`  | required |
| `disabled` | `boolean` | `false`  |
