## Installation

```bash
npx shadcn@latest add @fulldev/input
```

## Usage

```ts
import { Input } from "@/components/ui/input"
```

```astro
<Input />
```

`Input` renders a native `input` and passes every attribute through, so use
`type`, `name`, `required`, and `disabled` as in HTML. Pair it with
[Field](/astro/components/field/) for a label, description, and error.

## API Reference

Source: [`src/components/ui/input`](https://github.com/fulldotdev/ui/tree/main/src/components/ui/input)

`Input` accepts all native `input` attributes and `class`. It sets
`data-slot="input"` (override it with `data-slot`) and renders `multiple` only
when it is truthy.
