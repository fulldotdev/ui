faqs:
  title: Frequently asked questions
  description: About Fulldev UI, shadcn/ui and the two frameworks.
  faqs:
    - question: How does Fulldev UI relate to shadcn/ui?
      answer: Fulldev UI follows the shadcn/ui components, styles and presets, and adds blocks and extras for content-driven websites. It installs with the shadcn CLI.
    - question: Do I use it with Astro or React?
      answer: Both. In Astro, Fulldev UI gives you every component and block as native Astro components. In React, you keep the official shadcn/ui components and add the Fulldev blocks and extras.
    - question: Which styles does it support?
      answer: Every shadcn/ui style for Base UI, with any theme, font and radius. Pick one in Create, or start from a shadcn/ui preset code.
    - question: How do I update a component?
      answer: The components are your code. Add an item again with the shadcn CLI to get the latest version, and review the changes before you keep them.
    - question: What does it cost?
      answer: Nothing. Fulldev UI is open source under the MIT license.
