# UI **components** and **blocks** for <span class="text-primary font-bold">Astro</span> and <span class="text-primary font-bold">React</span>

Source files you own, installed with the shadcn CLI in every shadcn/ui style:
shadcn/ui components with their official examples, components for content
sites, and full-width page blocks.

| Edition | Start                                     | Components                       | Blocks                   |
| ------- | ----------------------------------------- | -------------------------------- | ------------------------ |
| Astro   | [Installation](/astro/docs/installation/) | [Components](/astro/components/) | [Blocks](/astro/blocks/) |
| React   | [Installation](/react/docs/installation/) | [Components](/react/components/) | [Blocks](/react/blocks/) |

Each page has the same page in the other edition, through the switcher in the
sidebar.

## For agents

Every page has a Markdown version at its URL plus `.md`, with the source of
each example. Per edition, [`/astro/llms.txt`](/astro/llms.txt) and
[`/react/llms.txt`](/react/llms.txt) list the pages and the registry setup.

```json title="components.json (Astro)"
{
  "registries": {
    "@fulldev": "https://ui.full.dev/r/styles/{style}/{name}.json"
  }
}
```

```json title="components.json (React)"
{
  "registries": {
    "@fulldev": "https://ui.full.dev/r/react/styles/{style}/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @fulldev/button @fulldev/button-examples @fulldev/hero-1
```
