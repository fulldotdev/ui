## Field

Use `Field`, `FieldLabel`, and `FieldDescription` to create an input with a
label and description.

<Example name="input-field" />

## Field Group

Use `FieldGroup` to show multiple `Field` blocks and to build forms.

<Example name="input-fieldgroup" />

## Disabled

Use the `disabled` prop to disable the input. To style the disabled state, add the `data-disabled` attribute to the `Field` component.

<Example name="input-disabled" />

## Invalid

Use the `aria-invalid` prop to mark the input as invalid. To style the invalid state, add the `data-invalid` attribute to the `Field` component.

<Example name="input-invalid" />

## File

Use the `type="file"` prop to create a file input.

<Example name="input-file" />

## Inline

Use `Field` with `orientation="horizontal"` to create an inline input.
Pair with `Button` to create a search input with a button.

<Example name="input-inline" />
