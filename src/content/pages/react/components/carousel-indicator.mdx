## Installation

```bash
npx shadcn@latest add @fulldev/carousel-indicator
```

This installs the [shadcn/ui carousel](https://ui.shadcn.com/docs/components/carousel)
too.

## Usage

```tsx
import { CarouselIndicator } from "@/components/ui/carousel-indicator"
```

```tsx
<Carousel aria-label="Product images">
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselIndicator index={0}>...</CarouselIndicator>
  <CarouselIndicator index={1}>...</CarouselIndicator>
</Carousel>
```

`CarouselIndicator` goes inside `Carousel` and scrolls to the zero-based
`index`, such as a thumbnail in a product gallery. The current one gets
`aria-current="true"` and `data-state="active"`. The index counts scroll
positions, which are the slides when one shows at a time.
