## Installation

```bash
npx shadcn@latest add @fulldev/aspect-ratio
```

## Usage

```tsx showLineNumbers
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9}>
  <Image src="..." alt="Image" className="rounded-md object-cover" />
</AspectRatio>
```

## API Reference

Source: [`react/src/components/ui/aspect-ratio.tsx`](https://github.com/fulldotdev/ui/blob/main/react/src/components/ui/aspect-ratio.tsx)

### AspectRatio

The `AspectRatio` component displays content within a desired ratio.

| Prop        | Type     | Default | Required |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | Yes      |
| `className` | `string` | -       | No       |
