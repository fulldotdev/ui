## Installation

```bash
npx shadcn@latest add @fulldev/number-field
```

## Usage

```tsx
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldIncrement,
  NumberFieldInput,
} from "@/components/ui/number-field"
```

```tsx
<NumberField name="quantity" defaultValue={1} min={1}>
  <NumberFieldDecrement />
  <NumberFieldInput aria-label="Quantity" />
  <NumberFieldIncrement />
</NumberField>
```

`NumberField` is the Base UI
[Number Field](https://base-ui.com/react/components/number-field) in the
shadcn/ui input group look. Set `name`, `defaultValue` or `value`, `min`, `max`,
`step` and `format` on `NumberField`. The buttons are named "Decrease" and
"Increase"; pass an `aria-label` in your language.
