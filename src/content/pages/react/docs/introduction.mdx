The React extension adds Fulldev UI to a project that already uses
[shadcn/ui](https://ui.shadcn.com/docs). It is not a replacement: Button,
Dialog and the other standard components come from shadcn/ui itself, with
their own [docs](https://ui.shadcn.com/docs/components).

- **Extras**: components for content sites that shadcn/ui does not have, such
  as `Section`, `Header`, `Logo`, `Price`, `Rating`, `Icon`, `Typography` and
  `Video`.
- **Blocks**: page sections built from the extras and the standard shadcn/ui
  components. They take plain content props and render native elements, so
  they work with any router and image pipeline.

Installing an extra or block adds only its own files. The standard components
it uses install from the official shadcn/ui registry, so your project keeps
one copy of each and your theme stays as it is.

The [Astro docs](/docs/introduction/) cover the full Fulldev UI library for
Astro.

Start with [Installation](/react/docs/installation/), then browse the
[extras](/react/components/) and [blocks](/react/blocks/).
