Fulldev UI for React installs as source files through the shadcn CLI, in every
shadcn/ui style.

- **Components**: the official shadcn/ui source for Base UI, plus Fulldev
  components for content sites, such as `Section`, `Logo`, `Price`, `Rating`,
  `Icon` and `Video`.
- **Examples**: the examples from the shadcn/ui docs, installable per
  component, such as `@fulldev/button-examples`.
- **Blocks**: page sections that take plain content props and render native
  elements, so they work with any router and image pipeline.

The [Astro edition](/astro/docs/introduction/) has the same blocks and
content components as `.astro` files.

Start with [Installation](/react/docs/installation/), then browse
[Components](/react/components/) and [Blocks](/react/blocks/).
