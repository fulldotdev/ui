## How presets work

A preset is a short code for a set of choices: style, base color, theme, chart
color, fonts, radius, and menu accent. The shadcn CLI turns the code into your
`components.json` style, CSS variables, and fonts, so the same code works on
[ui.shadcn.com/create](https://ui.shadcn.com/create) and here.

The style decides the shape of components. Fulldev UI installs each component in
the style from your `components.json`, through the `@fulldev` registry on
`https://ui.full.dev/r/styles/{style}/{name}.json`. The theme and fonts are CSS
variables in your stylesheet.

Your choice here also applies to the previews on every page of these docs. Use
Reset to go back to the default Fulldev UI look.

Fulldev UI uses Lucide icons, so presets keep the Lucide icon library. Menu
colors are not supported yet. Read more in [Presets](/docs/presets/).
