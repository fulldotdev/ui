## How presets work

A preset is a short code for a set of choices: style, base color, theme, chart
color, fonts, radius, menu color, and menu accent. The shadcn CLI turns the code
into your
`components.json` style, CSS variables, and fonts, so the same code works on
[ui.shadcn.com/create](https://ui.shadcn.com/create) and here.

The style decides the shape of components. Fulldev UI installs each component in
the style from your `components.json`, through the `@fulldev` registry on
`https://ui.full.dev/r/styles/{style}/{name}.json`. The theme and fonts are CSS
variables in your stylesheet.

Your choice here applies to all of these docs, previews included, and shows up
as "Your preset" in the switcher at the top of the docs sidebar. Reset goes back
to the Fulldev preset, the docs default. A new project gets the theme of the
registry's init item instead.

Fulldev UI uses Lucide icons, so presets keep the Lucide icon library. The
shadcn CLI applies menu colors to React components only, so the Astro components
install with the default menu color. Read more in [Presets](/docs/presets/).
