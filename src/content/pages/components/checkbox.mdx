## Installation

```bash
npx shadcn@latest add @fulldev/checkbox
```

## Usage

```ts
import { Checkbox } from "@/components/ui/checkbox"
```

```astro
<Checkbox />
```

`Checkbox` renders a native `input type="checkbox"` and accepts its
attributes, so it submits with a form and works without JavaScript.

## Checked State

Use the native `checked` attribute for the initial state. Read or set
`input.checked` and listen to the native `change` event to react to changes.
Set `input.indeterminate = true` in a script for the indeterminate state.

## Invalid State

Set `aria-invalid="true"` on the checkbox and `data-invalid` on the field
wrapper to show the invalid styles.

## API Reference

Source: [`src/components/ui/checkbox`](https://github.com/fulldotdev/ui/tree/main/src/components/ui/checkbox)

`Checkbox` accepts every `input` attribute except `type`, such as `checked`,
`disabled`, `required`, `name`, `value` and `aria-invalid`.
