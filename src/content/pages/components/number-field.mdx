## Installation

```bash
npx shadcn@latest add @fulldev/number-field
```

## Usage

```ts
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldIncrement,
  NumberFieldInput,
} from "@/components/ui/number-field"
```

```astro
<NumberField>
  <NumberFieldDecrement />
  <NumberFieldInput name="quantity" value="1" min="1" aria-label="Quantity" />
  <NumberFieldIncrement />
</NumberField>
```

`NumberField` is an input group around a native `<input type="number">`, as
data-slot leaves a number field to the browser. Set `name`, `value`, `min`,
`max` and `step` on `NumberFieldInput`; it submits with its form and works
without JavaScript. The buttons step the input as its arrow keys do and fire
`input` and `change`, so listen to the input only. They are named "Decrease"
and "Increase"; pass an `aria-label` in your language.

## Composition

```text
NumberField
├── NumberFieldDecrement
├── NumberFieldInput
└── NumberFieldIncrement
```

## API Reference

`NumberFieldInput` takes the attributes of `InputGroupInput`.
`NumberFieldDecrement` and `NumberFieldIncrement` take the props of
`InputGroupButton`, with `size` `"icon-xs"` by default, and render a minus or
plus icon unless you pass children.
