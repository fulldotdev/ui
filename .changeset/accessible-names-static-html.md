Select triggers show their text in the server-rendered HTML: an empty `SelectValue` gets the label of the `defaultValue` item, or the `placeholder`, the text Data Slot shows when it starts. Before, the trigger stayed empty, and had no accessible name, until the select script ran. `ComboboxTrigger` is named "Toggle" in the HTML, the name Data Slot gives it. Icon-only buttons in the button, collapsible, combobox, input group, item and tooltip examples have an accessible name.
